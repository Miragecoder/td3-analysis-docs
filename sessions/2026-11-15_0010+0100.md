# 2026-11-15 — Tracing opponent lane routes

## What changed

- Added a shared-bank opponent route tracer to the course editor. Pacific route
  paths can be toggled on the map; the route panel reports finish, early script
  termination, loops, unmatched exits, and same-cell U-turns.
- Matched the tracer's branch behavior to `sim_traffic.c`: entry waypoints are
  normalized before route-script/branch checks, and branch selection uses the
  active behavior before the next script value is applied.
- Added focused tests for matched links, scripted branches, lane entries,
  branch-mode ordering, and the engine's same-cell U-turn fallback.
- Confirmed train models `0x12`–`0x14` use the shared lane-following routine;
  behavior 8 halves their speed.
- Retained the inverted leg-3 finish on ground-road tile `0x30` beyond the
  preserved intersection. Its exit and finish entry have matching height 2;
  no elevation adjustment is indicated by the shared bank.

## Trace results

Using `SCENETTP.BIN` embedded in `DATAB.DAT`, both opponents reach the finish
without a fallback U-turn on every original Pacific leg. On the inverted map,
both traces show one fallback U-turn on leg 1. No fallback U-turn appears on
legs 2–5, but existing route scripts terminate before finish: one opponent on
legs 2 and 4, and both opponents on legs 3 and 5. This points to route-script
changes as necessary for a complete reverse course; it does not explain the
playtest report of U-turns on all legs.

The editor uses the shared lane bank only. A scene-specific `<scene>P.BIN`,
runtime start-state differences, initial headings, and steering remain
unverified. The overlay visualizes existing scripts; it does not automatically
generate or rewrite them.
