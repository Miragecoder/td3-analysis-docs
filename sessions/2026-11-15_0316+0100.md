# Starting reversed AI navigation

The editor now has a first implementation step for inverted-course navigation:

- It can reverse each lane record's waypoint order, swap entry and exit flags,
  and negate signed branch offsets.
- It serializes the result as a 127-entry private lane bank and offers it as
  `SCENE03P.BIN`.
- After inversion, route visualization uses the generated reversed bank so
  the displayed routes reflect the exported navigation data.

This is not yet a playable route conversion. Opponent start waypoints and
branch scripts are still copied from the source maps. Local route tracing
shows some opponents match their expected reversed paths, while others
terminate early or diverge. The generated P.BIN also still needs to be wired
into the game's scene-specific resource selection before it can be playtested.

Validation completed: all 28 editor tests pass, and `npm run build` succeeds.

## Closeout

The editor trace explains why inverted leg 1's Opponent 2 does not reach the
finish: its unchanged script has initial mode `3` and only two branch modes,
`[3, 2]`. After two same-cell U-turns it revisits tile `0x24` at `(6,13)`,
waypoint 6, and requests a third branch mode; the following zero terminates
the route and the game removes the opponent. Opponent 1 has three branch
modes and reaches the finish. Correcting Opponent 2's start index alone does
not prevent script exhaustion.
