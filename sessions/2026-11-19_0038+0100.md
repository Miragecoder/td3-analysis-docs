# SCENE03 private banks, shared lane bank, and junction investigation

Continued SCENE03 / three-way junction (`0x24`) work across the course editor
and analysis artifacts.

## Course editor (`repos/testdrive3-course-editor`)

- **SCENE03 experiment generation** now uses SCENE01's shared lane bank
  (`SCENETTP.BIN`, un-reversed, no mirroring/patching) as the private
  `SCENE03P.BIN`, serialized for the private bank (0x7F entries), instead of a
  globally reversed/patched lane bank.
- **Private O/P banks for the original engine:** generation loads the shared
  object bank (`SCENETT0.BIN`), embeds `SCENE03O.BIN`/`SCENE03P.BIN` into
  `SCENE03.DAT`, and updates the scene archive entries (hash/offset/stored
  size/flag). `createScene03LstFromScene01` marks the scene as owning O/P sets
  (`LST[0x57]=0`). Added optional `SCENE03O.BIN` export and UI/status text
  updates.
- **Lane helpers:** added `patchReversedTile24` in `lane-connectivity.ts` (for
  reversed-bank experiments; not used by the current shared-bank SCENE03 path)
  and kept `reverseLaneBank` behavior unchanged.

## Analysis / findings (edited `Game/SCENE03.*`, Leg 1)

- Verified `Game/SCENE03.DAT/LST` carry embedded private banks (`0x57=0`,
  matching `SCENE03O.BIN`/`SCENE03P.BIN`); `SCENE03P.BIN` is a copy of shared
  `SCENETTP.BIN` (unreversed).
- Corrected an earlier analysis error (map-cell rotation/elevation bit parsing):
  Leg 1 junction is `(6,13) 0x24 rot 270° elev 6` (entered from W at wp0), with
  valid lane links to `(5,13)/(7,13)/(6,12)`; `(6,12)=0x11 rot 180°` connects.
- Stored-script traces (shared bank, current map) produce the intended diverge/
  reconverge: Opp1 `init 2,[2,2,2]` exits E at `(6,13)` → `…→(28,11)→(29,11)`;
  Opp2 `init 4,[4,2]` exits N → `…→(28,11)→(29,11)`. This matches editor "Show AI
  route" for stored scripts; in-game divergence remains runtime/opponent-behavior
  sensitive (traffic can take the turn). "Generate AI paths" can produce/apply
  the desired Leg 1 routes (opponent starting waypoint states may need tuning).
