# Scene LST editor and PLAYDISK.DAT generator

Added two course-editor features for editing scene metadata strings and
generating PLAYDISK configuration files.

## Scene LST string editor and exporter

- Added a **Scene strings (LST)** panel to the course editor for the scene
  being edited, with editable fields for the **course name**, all 36 fixed
  **route name** slots, and the **UI strings** block.
- LST string edits are applied to an in-memory working copy with
  apply/reset controls and can be exported as an edited `.LST` file
  alongside the existing edited `.DAT` export workflow.
- Built-in `SCENE01`/`SCENE02` loads now keep a paired editable LST copy;
  custom DATs use the selected course’s LST template when available. LST
  export is disabled during the SCENE03 inversion experiment flow.
- Added `repos/testdrive3-course-editor/src/shared/scene-lst.ts` helpers to
  read/write the course name, route names, and UI strings within the
  1638-byte scene LST format, with fixed-size/fit validation.

## PLAYDISK.DAT generator

- Added a **PLAYDISK.DAT generator** page (`playdisk.html`) with a form to
  edit 14 car slots, 8 scene slots, selection/state words, and tail bytes,
  plus open/reset/export controls (179-byte output).
- Added `repos/testdrive3-course-editor/src/shared/playdisk.ts` for
  parsing/writing PLAYDISK data and a stock-style default template.
- Wired the generator into the Vite build and added navigation links from
  the viewer and course editor.
