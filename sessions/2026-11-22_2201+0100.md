# SCENE03 generation automation and editor fixes

## Context

Follow-up to SCENE03 work in `td3-analysis-docs/repos/testdrive3-course-editor`. Goal: automate the manual post-processing steps after invoking “Generate SCENE03”, then fix map/tile UI issues and remaining SCENE03 tile/horizon adjustments until the generated SCENE03 was fully playable.

## Changes (course editor)

### SCENE03 post-generation automation

- `createScene03LstFromScene01` now sets course name to `Yosemite - Pacific` and swaps LST route-name blocks for inverted maps `1↔5` and `2↔4` (`swapScene03RouteNames`).
- `invertCourse()` now always swaps leg 1/5 landscape sets A↔C:
  - palettes `0x12378 ↔ 0x257EA` swapped in-place;
  - `landA↔landE`, `landB↔landF` stored as scene image overrides so export can recompose slots that change size (fixed-slot in-place swap failed because E/B do not fit in A/F).
- Added `regenerateAllOpponentRoutes(...)` and run it for all 5 legs during SCENE03 generation, before final status. It probes finish-reaching no-U-turn paths, prefers diverge/reconverge different signatures, writes entity waypoint low bits and opponent branch scripts.
- SCENE03 generation now fetches and applies bundled title/icon PNGs as scene image overrides:
  - `images/SCENE03/yosemite-pacific-title.png` → `title`
  - `images/SCENE03/yosemite-pacific.icon.png` → `icon`
- Added `refreshSceneImageUI()` after generation so Scene UI bitmaps show updated overrides immediately.

### SCENE03-specific map patches (before AI route regen)

- Tile `0x58` (one-way three-way junction) replaced with `0x15` (bidirectional equivalent):
  - leg 2 / map index 1, `(3,11)`
  - leg 3 / map index 2, `(3,14)`
  - leg 4 / map index 3, `(28,14)`
  - leg 5 / map index 4, `(28,4)`
- Leg 3 starting tile set to `0x31` (`49`) using player entity `mapX/mapY` (slot 0 cell field can be stale).
- Leg 3 `(0,0)` cleared to `0x00`; it was a normal 180° rotation artifact from SCENE01 leg 3 `(31,15)` tile `0x5E`.
- Leg 5 Day sky accent / sky seed `0x30` set to `0x7A` (was `0x7B`).

### Map/tile UI fixes

- Cell properties popup now shows the actual selected cell’s tile ID; palette brush selection no longer overrides the Tile ID field.
- Tile ID label clarified as “Tile ID (tileset ref, 0–255)”.
- Added map “IDs” toggle (`#show-tile-ids`); tile ID overlays hidden by default via `.map-grid:not(.show-tile-ids) .tile-id { display: none; }`.

## Bugs found/fixed

| Symptom | Cause | Fix |
|---|---|---|
| Land A/E, B/F swap not visible after Generate SCENE03 | `swapScene01LandscapeSetsAandC` failed on fixed DAT slot sizes (`landE`>`landA`, `landB`>`landF`); also Scene UI bitmaps panel not refreshed | Swap palettes in-place and store swapped land images as scene image overrides; call `refreshSceneImageUI()` |
| Cell popup showed Tile ID 21 for every tile | `updateCellDetails` used `paletteTileId ?? cell.tileId` | Show `cell.tileId` |
| Leg 3 start tile patch didn’t take effect | Patch used stale slot 0 entity cell field | Use player entity `mapX/mapY` |
| SCENE03 leg 2/4 junction patches initially wrong coordinates | User correction | Changed leg 2 `(3,18)->(3,11)`, leg 4 `(24,14)->(28,14)` |
