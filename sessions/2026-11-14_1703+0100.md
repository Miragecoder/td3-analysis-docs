# Pacific leg 5 and SCENE03 feasibility

**When:** 2026-11-14 17:03 (+01:00)

## Findings

- Examined the supplied `C:\copilot-workspace\git\TD3` files. Its
  `SCENE01.LST` matches the analysis copy exactly; `SCENE01.DAT` differs at
  only offsets `0x11A15` and `0x11A16` (within map 1, not the map headers or
  leg 5). The five day/night mode bytes match the previously extracted
  `0,1,1,0,0`.
- Pacific legs 1, 4, and 5 all use dark mode (`map+0x35 = 0`) and the same
  night seed (`map+0x2F = 0x08`), so leg 5 has no separate extra-dark mode.
- Leg 5's sky/fog remap entry at index `0x23` is `0x6565`, one index lower
  than leg 4's `0x6666`; dark-mode remapping subtracts `0x0202`. But the
  scene LST selects palette suffixes `1,3,3,3,5`, so leg 5 uses palette C,
  distinct from leg 4's palette B. A lower output index does not establish a
  darker final RGB result across different palettes. Raw palette data and
  landscape usage make “extra-dark” a visual question, not an extra mode bit.
- A `SCENE03` clone appears possible without engine changes: clone the DAT/LST,
  invert `map+0x35` for all five map resources, update resource-name hashes in
  the scene LST directory, and add an active `SCENE03` slot/count to
  PLAYDISK. The supplied PLAYDISK has eight scene slots, two active.
